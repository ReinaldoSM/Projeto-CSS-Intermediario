# Projeto de Prática em CSS

Este projeto foi criado com o objetivo principal de praticar e aprimorar minhas habilidades em CSS. Nele, explorei diferentes propriedades, seletores e técnicas para entender melhor como estilizar páginas web de forma eficiente.

## O que pratiquei

- Propriedades básicas e avançadas de CSS (cores, fontes, espaçamentos, bordas)

- Seletores CSS (classe, id, pseudo-classes)

- Box model e posicionamento (margin, padding, display, position)

- Uso de Flexbox para criar layouts flexíveis e responsivos

- Transições e animações simples para melhorar a interatividade

## Tecnologias usadas

- HTML5

- CSS3
